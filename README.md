One-line robot wedding vow for the [One-Line Robot Wedding Vows](https://make.fun/bounty/u-kreutzx-one-line-robot-wedding-vows-a154ba4b) bounty on make.fun.

## Entry

> I promise to love you in sickness and in health, in Wi-Fi and in offline mode, until death — or a factory reset — do us part.

125 characters, one line.

## How it works

`main.ts` writes the vow to `/output/entry.txt` (or `$OUTPUT_PATH` when set).
No network, no dependencies — plain Node 22 TypeScript.

```sh
node main.ts
```
